# 00-开始使用

## 这个库解决什么问题

`CxMVault` 用来把每天看到的新文章、新知识、网页内容、截图、项目经验和排错记录，持续整理成可追溯、可复用、可被任何 agent 读取的个人知识库。

核心原则：

- 先收集，不急着分类
- 每天消化 inbox
- 每周复盘，把零散信息变成稳定知识
- 每个结论都能追溯到来源
- 旧项目经验不能丢，先桥接，再逐步编译

## 新东西放哪里

| 内容 | 放入位置 | 说明 |
| --- | --- | --- |
| 网页剪藏、博客、知乎、公众号正文 | `raw/inbox/web/` | 保存为 Markdown 或文本，文件名用日期开头 |
| 长文章、PDF、电子书摘录 | `raw/inbox/articles/` | 保留原文或摘录，后续再编译 |
| 截图、图片、报错图 | `raw/inbox/screenshots/` | 图片放这里，必要时配同名 `.md` 说明 |
| 本地文件、导出包、附件 | `raw/inbox/files/` | 保留原始文件，不直接改 |
| 临时想法、待判断信息 | `raw/inbox/ideas/` | 不确定归属时先放这里 |
| 项目任务沉淀 | `wiki/projects/` 或旧库桥接页 | 先查项目桥接页，再决定是否编译 |

## 每天流程

1. 把当天新增资料放入 `raw/inbox/`
2. 新建或更新 `reviews/daily/YYYY-MM-DD.md`
3. 让 agent 执行“每日消化”：读取 inbox、判断价值、写入 `wiki/` 或标记待复盘
4. 更新 `wiki/index.md`
5. 更新 `wiki/log.md`

## 每周流程

1. 新建 `reviews/weekly/YYYY-Www.md`
2. 回看本周 daily notes、inbox、wiki/log
3. 合并重复主题
4. 将反复出现的问题提升为 SOP、项目规则或概念页
5. 运行健康检查：

```powershell
& 'E:\AIWorkspace\CxMVault\tools\Test-CxMVault.ps1'
```

## 每月流程

1. 检查旧 `CodeXKnowledge` 还有哪些项目经验没编译进新库
2. 检查 `agentMemory` 桥接是否仍有效
3. 归档无价值 inbox
4. 更新 `wiki/overview.md` 和 `wiki/index.md`

## 你可以直接对 agent 这样说

```text
帮我消化今天 raw/inbox 里的新增内容，按 CxMVault 的 SOP 编译到 wiki，并更新 daily、wiki/index 和 wiki/log。
```

```text
帮我做本周复盘，把本周重复出现的问题、项目经验和可复用流程沉淀进 CxMVault。
```

```text
这张截图/这篇文章放进 CxMVault，先作为 raw source，再提炼成可追溯的 wiki 页面。
```
