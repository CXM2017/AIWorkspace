# raw

`raw/` 保存原始资料和来源证据。这里的内容默认不直接当作结论，只有经过每日消化或专题整理后，才编译进 `wiki/`。

## 子目录

- `inbox/`：新资料收件箱，每天消化
- `legacy/`：旧库和旧项目记忆桥接
- `personal/`：个人原始材料
- `projects/`：项目原始材料
