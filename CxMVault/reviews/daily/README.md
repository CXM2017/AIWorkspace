# Daily Reviews

每日笔记用于记录当天新增资料、消化动作、输出页面和未决问题。

命名：`YYYY-MM-DD.md`

每天至少记录：

- 今天新增了哪些 raw source
- 消化了哪些内容
- 更新了哪些 wiki 页面
- 明天需要继续处理什么
