# 方法论来源

## Karpathy LLM Wiki

采用 `raw/`、`wiki/`、`schema/` 三层：原始资料不可变，wiki 是 agent 编译后的知识，schema 是 agent 的维护契约。

落地到本库：

- `raw/` 保存来源
- `wiki/` 保存长期知识
- `schema/AGENTS.md` 保存跨 agent 规则
- `tools/Test-CxMVault.ps1` 承担 lint 角色

## PARA

PARA 强调按行动性组织资料：项目最可行动，资源偏长期参考，归档用于低频历史。

落地到本库：

- 项目经验进入 `wiki/projects/`
- 长期主题进入 `wiki/domains/` 和 `wiki/concepts/`
- 原始资料留在 `raw/`
- 不活跃资料后续进入归档区

## Johnny Decimal

Johnny Decimal 的价值是稳定入口和编号秩序。本库没有完全采用 00-99 全编号，但保留了关键入口编号：

- `00-开始使用.md`
- `wiki/index.md`
- `reviews/daily/`
- `reviews/weekly/`
- `reviews/monthly/`

## Obsidian 周期复盘

周期复盘用于防止 inbox 堆积和知识腐化。

落地到本库：

- 每日消化：`reviews/daily/`
- 每周复盘：`reviews/weekly/`
- 每月整理：`reviews/monthly/`
- 模板：`templates/`
